# Recorrido del repositorio en vivo

**Duración sugerida:** 2 minutos antes de abrir la app.

1. Abrir esta carpeta de muestra y explicar que resume SID, pero no contiene el código fuente.
2. Mostrar el orden inspirado en GanadApp: referencias, plan, caso de uso, arquitectura, datos, interfaz e implementación.
3. Abrir `03_ARQUITECTURA/arquitectura-simplificada.md` y explicar Compartir → Confirmar → Resultado.
4. Mostrar `07_IMPLEMENTACION/validacion.md` para distinguir pruebas aprobadas de evaluación humana pendiente.
5. Pasar a la demo de la aplicación real.

La app real y el repo fuente se muestran desde la computadora de Martín. No invitar al profesor como colaborador. Una presentación en pantalla no le da acceso a GitHub.
